\chapter*{Resumen}
Este Trabajo Fin de Máster propone una arquitectura multiagente para el
procesamiento, modelado y detección de anomalías en entornos industriales. El
caso de uso inicial se centra en rodamientos de motores eléctricos monitorizados
mediante señales de vibración. La solución combina agentes coordinados mediante
LangGraph con ejecutores Python deterministas, de forma que las decisiones se
representen mediante contratos estructurados y las transformaciones sobre datos
sean reproducibles, auditables y testeables.

\chapter*{Abstract}
This Master's Thesis proposes a multi-agent architecture for data processing,
modeling and anomaly detection in industrial environments. The initial use case
focuses on electric motor bearings monitored through vibration signals. The
solution combines agents coordinated with LangGraph and deterministic Python
executors, so that decisions are represented through structured contracts and
data transformations remain reproducible, auditable and testable.
