\chapter{Experimentos}

\section{Protocolo experimental}

Esta seccion documentara los experimentos ejecutados sobre CWRU Bearing Dataset.
Cada experimento debera indicar:

\begin{itemize}
  \item version del manifiesto;
  \item configuracion de ventanas;
  \item features o tensores usados;
  \item modelo e hiperparametros;
  \item estrategia de particion;
  \item metricas obtenidas;
  \item artefactos generados.
\end{itemize}

\section{Experimento base}

El primer experimento comparara modelos clasicos de deteccion de anomalias
entrenados con ventanas normales y evaluados contra ventanas normales retenidas
y ventanas con fallo.
