\chapter{Conclusiones}

\section{Conclusiones principales}

Esta sección resumirá las aportaciones del proyecto, separando los resultados
del pipeline, la arquitectura multiagente y los modelos de detección de
anomalías.

\section{Trabajo futuro}

Líneas previstas:

\begin{itemize}
  \item ampliar la validación con NASA IMS Bearing Dataset u otros datasets
        industriales mas complejos;
  \item incorporar modelos adicionales con ejecutores deterministas, como PCA
        con error de reconstruccion, One-Class SVM, LOF y autoencoders;
  \item aumentar el poder de decision de los agentes mediante contratos
        estrictos, alternativas justificadas y planes experimentales acotados;
  \item definir ejecuciones controladas desde API y Human Review antes de
        permitir trabajos costosos mediante `POST /runs`;
  \item añadir persistencia de checkpoints cuando sea necesaria para
        ejecuciones largas;
  \item preparar ejecución Docker y SLURM cuando el flujo local sea estable.
\end{itemize}
